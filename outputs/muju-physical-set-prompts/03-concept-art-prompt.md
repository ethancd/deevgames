# Prompt: three complete concept variants

Read the shared brief and completed research under `outputs/muju-physical-set-v1/research/`. Produce concept art for three coherent variants of the entire modular set. Use the available image-generation skill/tool for raster concept art, with actual Muju glyph/reference images as inputs. Save prompts, references, generated images, and a short design description for each variant under `outputs/muju-physical-set-v1/concepts/`. These images are design proposals, not CAD evidence.

Explore these three directions while retaining every locked requirement:

- **Chamfered:** crisp octagonal steps, clean planar faces, robust beveled glyph edges, minimal ornament, legible silhouettes.
- **Soft octagonal:** softened corners and tactile rounded edges while keeping an unmistakably octagonal base; gently rounded glyph profiles and quiet pedestal steps.
- **Turned/fluted:** restrained architectural molding, broad printable flutes or grooves, and stepped octagonal pedestals informed by the earlier Muju concept gallery. Ornament must not conceal the six canonical symbols or produce tiny fragile projections.

Differentiate silhouette, edge treatment, texture, and pedestal language, rather than simply recoloring one mesh. Use a common interface envelope if practical so component fit can be calibrated once. Keep color meanings identical across variants.

For each variant, create a manageable set of clearly labeled boards:

1. An overview showing the six colored glyphs assembled in ownership bases, both army colors, tier progression, loose phasing glyphs, a tile cluster, and cyan crystal stacks. Use a clean neutral background with realistic materials and enough contrast to see ivory and charcoal separately.
2. A construction study: side view and exploded view of T1/T2/T3, visibly preserving both lower additions at T3; a removed glyph with its keyed connection; a crystal stud/socket section; and tile interlocks. Add precise labels or dimensions as a separate vector/HTML overlay rather than trusting generated lettering.
3. A tabletop view showing medium-gray tiles, exactly two home tiles in the matching army colors when the full board is visible, and pieces amid resource stacks. Make size and hand access believable. Include an inset of a loose glyph coexisting with an occupying piece if current rules allow it.

Use this reusable image prompt structure, filling in the selected variant and reference inputs:

> Design study for a physically manufacturable FDM-printed Muju tabletop set, [VARIANT LANGUAGE]. Use the attached authentic Muju glyphs: red flame, yellow lightning bolt, blue droplet, purple crescent, green leaf, warm copper/orange-bronze anvil. Each colored glyph is a sturdy removable upright insert in an ivory or charcoal octagonal base. Promotions use visible additive layers: original base on a wider T2 pedestal, and both resting on a separate wider T3 pedestal. Show the complete three-layer T3 construction accurately. Square interlocking board tiles are medium gray except the ivory and charcoal home tiles. Each tile has four inset edge-midpoint studs supporting translucent cyan cubical resource stacks. Include loose glyphs lying flat for phasing. Show plausible printable thickness, gentle lead-in chamfers, robust joints, and realistic relative scale. Maintain the exact color roles and construction from the reference sheet. Composition: [OVERVIEW / EXPLODED CONSTRUCTION / TABLETOP].

Inspect every generated image. Correct missing parts, malformed glyphs, wrong metal color, opaque crystals, incorrect tier stacking, or invented accessories. Use CAD sketches for mechanical details where image generation remains ambiguous. Never carry an impossible AI-generated joint into the engineering design merely to match the picture.

Deliver a comparison explaining each variant's tactile qualities, readability, expected print complexity, and construction risks. Continue to model **all three** variants; do not stop here to ask which single variant should survive.
