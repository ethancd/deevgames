# Muju soundtrack

These are the nine selected full listening mixes, generated with ElevenLabs for
Muju Hono Tanka and published at the owner's request for personal/family listening.
Tanka includes the v3 low-medium middle-passage revision; Umeme is based on 19D.

The MP3s are copies of the approved listening files, without additional encoding.
`sources.json` records their original mix names, audition selections and SHA-256
hashes. Filenames contain a hash so replacements cannot reuse stale audio caches.
Update the corresponding entry in `src/music/tracks.ts` when replacing a mix.

Only these selected recordings are deployed. Generation credentials, raw trials,
personal review notes and provider request receipts remain outside this directory.
