# Web source ledger — Muju physical set v1

Accessed: **2026-09-30** for every row. Retrieval note: in this research session the network egress
proxy allowed **github.com (web + git clone) only**. Bambu Lab's wiki, store, product page and blog,
Prusa's knowledge base, Formlabs, Hubs, Xometry, Protolabs, Wikipedia, Google Patents, Printables,
gridfinity.xyz and all review sites were blocked (`EGRESS_BLOCKED`). Because of this, Bambu Lab
manufacturer facts below come from **Bambu Lab's own open-source slicer data (Bambu Studio on GitHub)**:
the machine, process, filament and color-code profiles Bambu ships to drive the H2C. That is
first-party data, but it is **slicer configuration, not marketing specs or a printing guide**.
Search-engine snippets were seen for some blocked pages. They are **not** used as evidence and appear
only in the "not retrieved" table.

"Page date" gives the commit date for repo files and the last-edited date for wiki pages, where one
was visible.
